# Security Policy

## Supported Versions

Only the current active release line receives security updates and patches.

| Version | Supported |
| ------- | --------- |
| 1.3.x   | Yes       |
| < 1.3.0 | No        |

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues or discussions.

Please report sensitive issues privately:
- **GitHub Security Advisory (Preferred):** [Open a private vulnerability report](https://github.com/Unheat/Kites/security/advisories/new)
- **Direct Email:** Contact `anbi2682006@gmail.com` with subject `[Security] Kites Vulnerability Report`

### Information to Include
- Description of the vulnerability and its potential impact
- Affected component (Chrome extension client or Cloudflare Worker backend)
- Reproduction steps or proof of concept
- Affected versions and browser environment

### Response Process
- Acknowledgment within 48–72 hours
- Status updates as the issue is verified and patched
- Release of fix and public advisory upon resolution
