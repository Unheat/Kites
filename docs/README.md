### 🏛️ System Architecture & Subsystems
1. **[System Architecture Overview](architecture/overview.md)**
   - Manifest V3 Chrome Extension topology and runtime boundaries
   - Background service worker messaging and explicit RPC targeting
   - Persistent Offscreen Document sandbox for WebGPU/WASM
   - Dexie schema v6, configurable retention for eligible history, and project-membership exemption
2. **[Translation Pipeline & Algorithm Guide](architecture/pipeline.md)**
   - 1D vertical tiling for tall webtoons ($h \ge 2500\text{ px}$)
   - PaddleOCR DBNet rotated polygon detection and projective crop recognition
   - 14-stage geometric and text noise filtering battery
   - Kruskal Minimum Spanning Tree (MST) bubble clustering
   - Language-aware panel reading order (`sort_regions` row-band clustering)
   - Polygon-strict neural inpainting (LaMa Manga & AOT-GAN 64px dynamic patch bucketing)
   - Keyed JSON Protocol for dialogue translation
   - Contour DP, Auto Balloon fitting, rectangular layout, and affine Canvas placement
3. **[Cloudflare Zero-Cost Worker Backend](architecture/backend-worker.md)**
   - Edge gateway routing (`api.12094852.xyz`) and Cloudflare WAF integration
   - Google OAuth token verification with SHA-256 cryptographic anonymization
   - Durable Objects with SQLite: rolling 24h quota enforcement with single-upsert optimization
   - Multi-provider waterfall (Mistral, Groq, Google AI Studio, OpenRouter, Workers AI)
   - Token-normalized EMA adaptive timeouts and circuit breaker cooldowns
   - Pre-deploy preview and staging verification workflow
4. **[Content Script & Media Subsystems](architecture/content-script-and-media.md)**
   - Universal Media Discovery: `MediaTarget` abstraction and hidden backing surface resolution (Twitter/X, Pixiv)
   - SVG placeholder filtering (Issue #2 Roliascan queue wedge fix)
   - CSS Anchor Positioning for in-page translation buttons with 3px hover race halo guards
   - SPA image replacement & `MutationObserver` reversion shield with `isSelfMutating` recursion guard
   - Screen Crop translation tool: Xnip-style viewport capture and retina display normalization
5. **[Studio Editor & Typesetting Architecture](architecture/studio-and-typesetting.md)**
   - Clean Plate Storage: non-destructive separation of background plate and structured text blocks
   - Interactive 8-handle bounding box manipulation and zoom/pan viewport normalization
   - Typography font preset registry (Wild Words, Anime Ace, Comic Hand, etc.)
   - Background color sampling: luminance contrast detection for white-on-black vs black-on-white text
   - Route-specific fitting, positioned-line restore, Canvas export, and documented parity limits
6. **[AI Models, Runtimes & Hardware Acceleration](architecture/models-and-runtimes.md)**
   - Hardware detection: WebGPU JSEP shaders with automatic WASM SIMD fallback
   - Complete PaddleOCR registry tiers (`v6-small`, `v6-medium`, `v6-tiny`, `v5`, `v4`, `v3`)
   - Inpainting models: LaMa Manga (Fast Fourier Convolutions), AOT-GAN (Contextual Transformations), and Simple Adaptive Polarity
   - Translation engines: WebLLM (MLC-AI WebGPU), Cloudflare Shared Pool, Google Translate, Custom API
   - Persistent browser Cache API (`kites-model-cache`) and monotonic download progress reporting

### 📋 Architecture Decision Records (ADRs)

Key technical decisions and architectural trade-offs are documented under [`docs/decisions/`](decisions/):

- **[ADR-001: Persistent Offscreen Document for WebGPU & AI Runtimes](decisions/ADR-001-manifest-v3-offscreen-document-webgpu.md)** — Why heavy compute runs in an Offscreen Document rather than a Service Worker or Web Worker.
- **[ADR-002: Polygon-Only Contract for Inpainting Engines](decisions/ADR-002-polygon-only-inpainting-contract.md)** — Why inpainting engines strictly receive character polygon masks and never rectangular bounding boxes.
- **[ADR-003: Keyed JSON Protocol for Dialogue Translation](decisions/ADR-003-keyed-json-protocol-for-llm-translation.md)** — Why Keyed JSON replaced delimiter-tagged prompts for LLM dialogue translation.
- **[ADR-004: 1D In-Memory Canvas Tiling for Tall Webtoons](decisions/ADR-004-1d-in-memory-tiled-ocr-for-webtoons.md)** — Why 1D in-memory canvas tiling was chosen over DOM splitting or viewport scrolling.
- **[ADR-005: Dexie IndexedDB Clean Plate Storage Architecture](decisions/ADR-005-dexie-indexeddb-clean-plate-storage.md)** — Why clean inpainted backgrounds are persisted separately from text blocks.
- **[ADR-006: Hybrid Bubble Detection & Conservative Sub-Chamber Partitioning](decisions/ADR-006-hybrid-bubble-detection-and-conservative-subchamber-partitioning.md)** — Why single balloons expand into safe cores while ambiguous multi-lobe balloons safely fall back to the exact Disabled tier.
- **[ADR-007: Alexandru Telea Fast Marching Method (FMM) Inpainting & Centralized Inpaint Catalog](decisions/ADR-007-alexandru-telea-fmm-inpainting-and-centralized-catalog.md)** — Why native Telea FMM was implemented to provide 0MB line-preserving inpainting and why inpainting tiers are centralized.
- **[ADR-008: Dual Typesetting and Typography Invariants](decisions/ADR-008-dual-typesetting-engine-and-advanced-typography-invariants.md)** — Historical decision; its two-engine taxonomy is superseded by ADR-010.
- **[ADR-009: On-Demand Font Library and Shared Picker](decisions/ADR-009-on-demand-font-catalog-and-koharu-2d-contour-invariants.md)** — Catalog integrity, imports, IndexedDB storage, document-local registration, and distribution limits.
- **[ADR-010: Contour Layout Metadata and Browser Validation](decisions/ADR-010-contour-layout-and-browser-validation.md)** — Three active strategies, coordinate ownership, stored line placements, and evidence required for parity claims.
